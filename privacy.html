Politique de confidentialité

Voici comment Archive 18 utilise et protège vos données personnelles.

Mode invité

Aucun compte n'est requis pour utiliser Archive 18. Sans compte, vos fiches, notes et photos restent sur cet appareil ; l'application n'envoie aucune copie de ce contenu à nos serveurs. La vérification du statut Premium peut transmettre des identifiants techniques à RevenueCat et à la boutique de votre appareil.

Données locales

Les personnes, entrées, notes, préférences et photos ajoutées sont conservées localement dans une base IndexedDB. Sur mobile, la clé de chiffrement locale est stockée dans le trousseau système lorsque la plateforme le permet.

Création de compte (facultative)

Vous pouvez créer un compte avec votre adresse email ou le service de connexion proposé sur votre appareil. Le compte est facultatif pour utiliser le journal local.

Sauvegarde cloud (facultative)

Si vous vous connectez, le journal est synchronisé automatiquement. Les données sont chiffrées sur l'appareil avant l'envoi à Supabase. La clé de synchronisation est gérée à partir de votre compte : l'opérateur du service pourrait techniquement retrouver cette clé. Il ne s'agit pas d'un chiffrement à connaissance nulle. Les photos cloud sont réservées à Premium.

Prestataires utilisés

Supabase gère les comptes et héberge les sauvegardes chiffrées dans le projet Archive 18 direct. RevenueCat vérifie le statut Premium. Les paiements sont traités par la boutique de votre appareil. Aucun contenu de journal ni photo n’est envoyé à RevenueCat.

Conservation et suppression

Les données locales restent sur l'appareil jusqu'à leur suppression manuelle ou la désinstallation de l'application. Les données cloud restent stockées tant que votre compte existe. La suppression du compte efface définitivement les données cloud associées.

Vos choix

Vous pouvez à tout moment effacer les données locales depuis Réglages, demander la suppression du compte et des données cloud depuis Réglages ▸ Compte, ou arrêter la synchronisation en vous déconnectant.

Contact
